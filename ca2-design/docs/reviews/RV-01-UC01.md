## What was checked

I went through the UC01 files and compared them against each other.

1. I checked the SSD, the contract and the first message in each sequence diagram use the same name and parameters. They do, for both makeBooking and checkAvailability.
2. I went through each postcondition in the contract and looked for the message in seq-makeBooking that makes it happen. Two didn't line up (rows 1 and 2).
3. I checked every failure in the contract has an alt branch and a Gherkin scenario. Some didn't (rows 3, 4 and 5).
4. I checked every message in the sequence diagrams is an operation in the class diagram. They all are. The create() messages aren't in the class diagram, but they're constructors, so that's fine.
