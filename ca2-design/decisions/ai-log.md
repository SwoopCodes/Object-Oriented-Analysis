# AI use log

Shared AI log for CA2, as required by Section 12.1 of the CA2 brief. AI is used at Level 3.

## How to use this log

- Add a row each time you use AI on CA2 work
- If an AI suggestion changes the shared baseline (a rule, a contract, a responsibility), it needs group discussion, a decision record and a PR review. Add the DR and PR link to the row
- Members can keep their own log instead. If so, link it in the Individual logs section below
